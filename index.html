How can a network remember an example?

A visual introduction to temporary synaptic memory, built one small idea at a time.

A trained neural network normally keeps the same parameters while it answers a question. Yet a useful example can change what the network does next. To understand how, we need to separate two kinds of memory.

01

Two speeds of learning

Slow parameters preserve knowledge acquired during training. Temporary state records what happened in the current session. Move the slider to see which part changes after a new demonstration.

Only the temporary state responds. The trained parameters remain fixed throughout this article.

02

A demonstration leaves a trace

The cue and action become active together. This creates an association between them. Increase the write strength and follow the path from the blue cue to the left action.

Path thickness represents the stored association. It is a direct view of the value, not a decorative animation.

03

Repetition strengthens recall

One example creates a weak trace. Compatible examples add evidence to the same route. Slide from one to five examples and compare the resulting strength.

The trace grows quickly, then approaches a ceiling. More evidence cannot push strength beyond 100 percent.

04

Temporary memory fades

A short-term trace is useful because it can change. The same flexibility also means it can fade. Increase the delay to see how much of the original association remains.

Every step keeps 86 percent of the previous value. This retention rate is an exposed teaching assumption.

05

A cue reads the stored route

Memory matters only when it changes a decision. Adjust the cue match. A close match activates the stored route strongly; a poor match produces an uncertain read.

The displayed confidence equals stored strength multiplied by cue match. Both inputs remain visible.

06

Conflicting examples compete

Now the same cue points to two different actions. Shift the balance between the original example and the contradiction. The stronger route determines recall.

At the midpoint the model is uncertain. On either side it selects the route with more evidence.

07

Order changes what survives

Temporary updates are sequential. Earlier examples have more time to fade. Move the latest example through the sequence and watch the balance shift.

A contradiction placed later has greater influence because fewer decay steps follow it.

08

One memory has limited room

As more cue-action pairs share the same temporary state, their traces begin to overlap. Increase the number stored and inspect how clearly each route remains separated.

Overlap is a limitation of this compact representation. It is not proof of a fixed capacity in every fast-weight system.

09

Strong traces resist noisy cues

A new cue is rarely identical to its demonstration. Add noise to the cue and compare a weak one-example memory with a stronger repeated memory.

The strong trace keeps a larger margin. This is toy-model behavior, not a reported benchmark result.

10

What this model can claim

The final comparison separates the live model from the research connection. Move across the scale to inspect which statements are demonstrated here and which require evidence from full architectures.

Demonstrated here: a temporary state can store, decay, and overwrite cue-action associations under the stated equations.

Supported by primary research: fast weights and synaptic-plasticity mechanisms can provide rapidly changing state in larger learned systems.

Not established here: biological realism, full BDH or BDH-CQ reproduction, or general reasoning ability.
