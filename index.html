How can a network remember an example?

A visual study of temporary memory, and how a recent example can shape the next decision.

Most neural networks learn before we use them. Training adjusts millions of parameters, and inference applies those parameters to new inputs. In the usual picture, answering one question does not rewrite the network for the question that follows.

Demonstrations complicate that picture. If a system sees a blue circle paired with “move left,” we may want it to reuse that pairing a moment later without starting another training run. One way to do this is to keep a small, rapidly changing state beside the network’s durable knowledge.

The diagrams below isolate that temporary state. Each one introduces a single operation, exposes its assumptions, and shows the quantity that changes.

01

A familiar digit can leave a temporary route

Begin with a small, concrete classifier. Its input is a 5 by 7 image, its middle units collect useful features, and its output units vote for the digits 1, 2, or 7. The permanent weights already make “2” the leading answer, but only narrowly.

Now imagine that the same handwritten 2 appears several times in the current lesson. A fast Hebbian trace is added to the ordinary network. It strengthens the active route from this image, through its feature unit, to output 2. The permanent classifier itself is not retrained.

The increasing line width is an actual value in the demonstration. Each sighting adds less than the previous one, so the trace approaches a bound. The bars at the output recompute the three scores from that trace.

This is a deterministic teaching classifier, not a trained MNIST benchmark. Its purpose is to expose exactly where temporary plasticity enters the computation.

02

Hebbian learning turns co-activation into a local update

Hebbian learning uses information available at the connection itself. If a sending neuron and a receiving neuron are active together, the connection between them is strengthened. A simple rate-based form is:

Δwij=ηxiyj

Here, xi is the sending neuron’s activity, yj is the receiving neuron’s activity, and η is the plasticity or learning-rate factor. If either neuron is inactive, their product is zero and this simplified rule makes no update.

The grid below shows every possible connection from a small input layer to a small output layer. One co-active pair selects one cell.

Increasing η makes the same experience produce a larger weight change. A value near zero makes the network stable but slow to adapt. A larger value creates a strong trace quickly, but also makes later contradictions more disruptive.

This is a simplified Hebbian rule. Practical systems often add decay, normalization, bounds, or learned modulation.

03

An associative memory completes a damaged shape

A small associative shape network is an auto-associative memory: the desired output is the same pattern as the input. During writing, co-active pixels strengthen one another. During recall, the visible pixels vote for the missing pixels that usually accompany them.

The cue below is a damaged 5 by 5 arrow. Increase the number of Hebbian writes and watch the recalled pattern become complete. This is pattern completion, not ordinary classification, because the network reconstructs the item it was shown.

The central H stands for the temporary association matrix. Its entries are built from pairs of active pixels. A partial cue activates that matrix, and the resulting votes restore pixels that are absent from the cue.

The staged recovery is intentionally visible. A full Hopfield update can settle abruptly once the cue has enough overlap with a stored pattern.

04

Short-term dynamics appear when the trace decays

If every Hebbian update permanently changed the network, a brief session could damage knowledge learned over months of training. Fast-weight systems instead combine a stable contribution with a temporary trace:

wijeffective=wijslow+αHij(t)

The slow weight is learned during training. The Hebbian trace H changes during the current sequence. The factor α controls how much the recent association can affect the network now.

Advance the delay below. Rather than plotting an abstract decay curve, the demonstration applies the decaying trace to the same recall task. Recovered pixels disappear as the stored association becomes too weak to support them.

This is the short-term dynamic: learning writes the arrow quickly, recall uses it for the next few steps, and decay removes it without altering the durable network.

Each step retains 84 percent of the previous trace. Pixel loss is a readable thresholded view of that continuous value.

05

Recall begins by matching the cue

Writing a memory is only half of the process. To use it, the current cue must align with something already stored. A close match activates the associated action; a poor match should not trigger confident recall.

The radial field represents possible cue directions. The movable point is the cue presented at test time. Dark arrows indicate the portion of the field considered similar enough to participate in the read.

At high similarity, the test cue retrieves the stored route. Lower the match and the evidence falls below the simple decision threshold.

Displayed confidence equals stored strength multiplied by cue match. Both quantities are visible and deterministic.

06

Contradictory examples share the same evidence

Suppose the blue circle is first paired with “move left,” then paired with “move right.” The cue now supports two incompatible actions. A useful model must expose this conflict rather than hide it behind a confident answer.

The horizontal balance divides a fixed amount of evidence between the original route and its competitor.

As contradictory evidence grows, the original action loses its advantage. At an even split, neither route deserves to win.

The model selects the stronger side. An exact tie produces an uncertain result.

07

The order of examples changes the result

Temporary updates happen in sequence. An early event is repeatedly reduced by later decay, while the final event reaches the test with most of its strength intact.

The five positions below form a short demonstration history. Four support left. One supports right. Move the conflicting example through the sequence.

The set of examples never changes, but their final influence does. This is why a fair evaluation should test more than one presentation order.

A contradiction placed later has greater influence because fewer decay steps follow it.

08

A compact memory eventually becomes crowded

Real tasks contain more than one cue and one action. Each additional relationship needs somewhere to live, but a fixed temporary representation offers only finite separation between traces.

The grid begins with distinct occupied cells. As more associations are added, the active cells become harder to distinguish from one another.

This does not specify a universal capacity limit. It shows the more general problem: adding information to a shared state can make individual relationships less distinct.

Overlap is a limitation of this compact representation. It is not proof of a fixed capacity in every fast-weight system.

09

Reinforced traces tolerate imperfect cues

A test cue is rarely identical to the example that created a memory. Its shape, position, wording, or context may differ. We can treat those differences as noise that weakens the read signal.

The solid curve begins with a reinforced memory. The dashed curve begins with a single example. Increase cue noise and compare how long each one remains usable.

Repetition creates a larger starting margin, so more corruption is required before the reinforced trace becomes weak.

This is a controlled property of the toy equations, not a reported benchmark result.

10

Keep the evidence boundary visible

The demonstrations establish how this particular teaching model behaves. They do not establish that every learned system uses the same equations, or that the simplified state is biologically realistic.

The scale separates three levels of confidence. The first is directly observable in this page. The second comes from published work on fast weights and plastic computation. The third would require substantially broader experiments.

Demonstrated here: a temporary state can store, decay, and overwrite cue-action associations under the stated equations.

Supported by primary research: fast weights and synaptic-plasticity mechanisms can provide rapidly changing state in larger learned systems.

Not established here: biological realism, full BDH or BDH-CQ reproduction, or general reasoning ability.

The useful conclusion is deliberately narrow. Temporary state offers a plausible computational bridge between a demonstration and the next decision. Its value depends on how information is written, retained, retrieved, and protected from interference.
